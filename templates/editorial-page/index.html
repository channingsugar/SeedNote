03.o · Evidence

Media Switch

封面卡，缩略图换主图

怎么用

  1. 组件从源稿可复用模块拆出。之后同类块必须用这些 class，不要另起皮肤，也不要发明一次性名字。
  2. 格子里带〔〕的是占位。整句换成调研原文；〔〕不要带进报告。
  3. 厚卡、问答行、机会行：条目留在该模块里，不要抬成新的一排。
  4. 运输卡用底部缩略图换主图。城市通航交互网络、视频播放器不是组件，压成图或文字小结。
  5. 报告翻页仍用 Grid 1–4 / Evidence / 全屏。一个 Grid 只放一种 Content。
  6. 来源写一次。源格没有口径句，就不要补。
  7. 这是分屏模板。流式是另一套：templates/editorial-flow/。两套不能互切。
