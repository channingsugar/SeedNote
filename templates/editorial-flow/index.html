文档栏

流式适配

文档栏。Grid 1 起是全量组合，看栏宽、吸顶、掉列和高度。

F.a · 流式

壳

栏宽 · 导航 · 高度

文档栏，不是把分屏竖着叠

这是流式模板，不是把分屏竖着叠。壳从一开始就是文档栏：栏宽约 1160 居中，导航 52px 吸顶，模块高度跟内容走。

封面仍整页。其余章封面收成文档大标题。目录里每个组合上方有一行菜谱，方便核对一行几个、变窄怎么掉列。报告不要带 data-catalog，那时这行菜谱不会出现。

F.b · 流式

标题

章判断 · 小节 · 开口句

目录对稿留标题，报告只留章判断

目录：章封面当 h2，每一组合的组件名当 h3，方便对稿。报告：一章一句判断（data-flow-title，没有就用导航名），多格、图、表不再重复屏标题；只有 1 格 copy / point 留下开口句。

章题要用主张句，不要只用导航两个字。不要加分屏切换，也不要抄 editorial-default 的翻页壳。

01.a · Grid 1

纯文字

一格 · 标题 + 正文

〔范围〕背景、边界或材料撑不住什么

〔正文〕写成完整段落。先回答这一屏的问句，再写条件和例外，最后写材料撑不住什么。不要拆成列表，也不要写成判断句。

〔续段〕需要第二段时换行接着写。没有第二段就删掉这段。

〔判断〕有主语、有动作，能讲出口

模板使用说明

  1. 格子里带〔〕的是占位。整句换成调研原文；〔〕不要带进报告。
  2. 〔〕里是槽名，后面是填法。页眉组件名（纯文字、观点、Grid 1）是目录，不要改。
  3. 封面填：题域、主判断、开场、副题、章数、稿件类型、作者、日期。
  4. 先定 Content，再选 Grid。一个 Grid 只放一种 Content。
  5. Grid 1 / 2 / 3 / 4 / 5–9 / 10+。列表和步骤一条就是一格。Grid 3 / 5–9 / 10+ 的编号列表用纵向。5–9 一次铺开，超过 9 格折行，不要横滑。
  6. 表和条整块占一格，宽度铺满，行间有分割线。可以上下滚动，不显示滚动条。有出处才写「数据来源」并挂链接；没有出处这一行不出现。字号 Caption（12），放在白卡内容区，居中。
  7. 单元格里 加粗 用 strong，强调 用 em（强调色 + 加粗）。同一张表里示意即可，不要另开强调组件。
  8. Evidence 单独成章：现场图、截图、横屏、条带、Media Switch。不进 Grid 格。封面默认并排多张。
  9. 全屏单独成章：有图、无图，或只有图。永远 1 块。
  10. 视觉由设计 Token 驱动。主题栏固定在左下角。右键文字编辑、右键图片替换。用导航和滚动阅读。
  11. 这是流式模板。分屏是另一套：templates/editorial-default/。两套不能互切。报告不要抄 data-catalog；章判断写在第一屏的 data-flow-title。10+ 格折行 3 列，不要横滑。
