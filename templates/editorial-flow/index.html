怎么用

  1. 这是流式模板。壳是文档栏：report-shell.is-flow、吸顶导航栏 .topbar、flow-stack 上下叠。封面右键切版式：左齐 / 居中 / 配图 / 图文分栏（data-cover：省略、center、image、split）；配图封面可右键替换图片，也可勾选「动效背景」切换 Ribbon Field / Halftone Flow / Matrix Field / Stream Convergence。拖组件排序时封面不显示。
  2. 合并后的父组件：.stat-card / .stat-grid 数字信息（横排数字是同一父组件的紧凑排：.stat-grid.is-compact；右键勾选前缀 / 后缀 / 说明，列数 2–5）；.info 编号信息（布局：格子 A 左侧竖线 / 格子 B 四周框 data-grid="b" / 列表 A stack / 列表 B row；data-pos 顶部 / 左侧；data-index：数字 / alpha / q 问题 / label 标签 / off 隐藏，即原无编号；.is-lg / data-no="lg" 大编号；格子列数 2–5；勾选「背景」data-bg 后可设 --info-bg（默认纯色 --tint-2，不用渐变）；整组右键勾选「配图」，图在一组信息的左 / 右 data-aside；配图可换裁切 / 可滚动 / 宽图 / 海报，底部保留 figcaption。尺寸只拖配图外框（和图片组一样），内部图高度始终铺满外框，拖高时整组与左侧信息跟着变高、不裁切文字和说明）；.point 观点（.is-soft 浅底）；.shot 图（data-kind：photo / crop / scroll / wide / poster；右键新增一条，列数 1–5；尺寸拖高后行均分、铺满裁切且不超出容器）。
  3. 组件库必须带基础 token：间隔 --s-in / --s-stack / --s-chapter；字号 --t-h1 / --t-num / --t-no-lg / --t-body / --t-aux；颜色 --c-text 档、--c-line、--c-accent、表数据栏 --c-pos / --c-neg；分割线 .rule / .rule.is-soft。
  4. 仍独立：公式、议题格 .pain-text-list / .pain-topic、自定义文本 .finding、图文卡 .transport-cards / .transport-card、韦恩图、导语、来源、章头、分割线、导航栏 .topbar、折线图 .rail-growth-chart、四象限矩阵 .ansoff-grid、漏斗图 .hotel-funnel-chart、关系网络 .hotel-city-network、节点表 .network-node-table、排行榜 .hotel-ranking-block。关系网络和节点表是两个父组件，不要包在同一块里。
  5. 同类块用父组件 + 变体，不要另起皮肤，也不要再收成 flow-block。
  6. 公式、韦恩图、提问、议题格、图文卡只保留内容。章头 .slide-head、分割线 .rule、导语 .research-lead 是独立组件，不要画进这些块。报告里章头下方仍必须紧跟强线，那是排版规则，不是组件自带的。
  7. 报告中每个主标题（.slide-head）下方必须紧跟一条可见的强线 .rule，不得省略，不得用下一块顶线替代，CSS 不得把这条线 display:none。小节标题下不加线，只用间隔。其余块之间不加线，只靠间距。表 / list / 卡内部只用 1px 弱线。编号信息不超过 4 条用 data-layout="cols"（编号在上），5 条及以上才用 stack。
  8. 间距分三档。区内 --s-in（16，含章头→强线）；章内换排 --s-stack（40，含强线→第一块）；换章 --s-chapter（96）。来源贴在所属证据块下面，不要和换章同一档。
  9. 格内条目留在该卡里。例如议题格的百分比、图文卡的属性行，不要抬成新的一排。
  10. 来源写一次。源格没有口径句，就不要补。
  11. 没有源 HTML 时：从 templates/editorial-flow/report.html 生成报告。对照目录选父组件，缺了才新增。不要抄 data-catalog，报告导航用 .topbar。主题导入导出只在本目录页，不要做到报告壳上。
  12. 分屏是另一套：templates/editorial-page/。旧稿在 templates/draft/。报告不要抄 data-catalog。导航用 .topbar。
  13. 结构说明：两张截图卡是同一父组件 .shot，photo / crop 变体；图区坏图时不把 alt 再写一层，标题只留在 figcaption。宽图和方案图也是同一父组件：.shot[data-kind=wide]，方案只是 .shot-plan 标签槽，目录收在「图 · 宽」。提问是 .info-grid[data-layout=row] 的问答内容，不是新父组件；底下浅底格是关掉编号的编号信息，不要画进提问。关系网络舞台高度跟左右列表走，不要写死 min-height。图 / 表 / 折线右键「尺寸」可拖宽高；折线拖高后绘图区跟着拉高，改数字后纵轴刻度自适应。韦恩图第三圈保留，圈内文案是该集合自己的判断。公式和韦恩图只在组件区出现一次。公式与数字信息不是同一组件：公式是算法，数字是支撑数字。四象限矩阵目录用代码版 .ansoff-grid。基础 token 右键改数值，立刻作用于整页并写入当前主题，可导出 JSON 在本目录导入。颜色 token 点色块用取色器，也可改 hex。议题四格是同一父组件 .pain-topic 铺进 .pain-text-list，目录名「议题格」；01–04 主题不同，不把正文并成一块。图文四卡是同一父组件 .transport-card 横排进 .transport-cards，目录名「图文卡」；导语不画进卡。图廊主图不另写当前图名，缩略图才是切换槽，不是第二个组件。
