# seed-edit

只给流式模板 `templates/editorial-flow/` 用。分屏 `editorial-page` 用自己的 `assets/template.js` 编辑器，不要挂这份。

- 顶栏最右侧「演示 / 编辑」切换（`html.is-seed-presenting`）：演示态关闭右键、排序、新增、就地改字，只留阅读与看图。顶栏不要「新增组件」按钮
- 空白处右键仍出原来的编辑菜单；只有点菜单里的「新增组件」才打开右侧悬浮卡片面板，再点卡片插入。卡片预览在图框里居中。插入「章头」必须带上 `.sub` 导语（标题下、分割线上方）和强线，不要只插标题和线，也不要把这句导语放到线下面。自定义文本在独立导语块下。章头 / 小节标题 / 导语 / 来源 / 分割线 / 自定义文本不配图，库卡片纯文本、不要配图预览
- 文字右键 →「编辑」→ 就地输入 → 点「完成」才提交（Esc 取消；回车只换行，不提交）。粘贴只进纯文本，不带原格式。选中后可改颜色、加粗；点旁边 token 色块即可换成主题色；自定义文本还可改字号、插入弱分割线，线为整行
- 标题右键 →「删除标题」：只删该章头 / 小节标题和紧跟的强线，不要把后面的章节内容一起删掉
- 顶栏 tab 由每一个章头「题域」`.kicker` 生成（封面固定为「封面」），同一章里后补的章头也要出 tab。没有题域的空章不要出 tab。改题域文字会同步改 tab。点 tab 滚到该枚章头（不要滚到整章 `section`），即时改 `scrollTop`，短锁高亮，末章底部垫高
- 视频不看大图，进度条可点可拖；`controls` 一直在，播放条用 CSS 默认隐藏、悬停才出现。persist 去掉 `data-seed-video-hover` / `is-seed-hover-*`，不要靠这些属性跳过绑定
- 用「打开报告」的 HTTP 打开时，以磁盘 `index.html` 为真相：不要把 IndexedDB 里的旧 markup / 尺寸套回页面，打开时也不要自动整页保存。hydrate 不要拆 `.point` 里非 `span` / `p` 的正文
- 观点 `.point` 默认左标签右正文、正文左对齐；浅底 `.is-soft` 单列左对齐，不要把正文推进第 2 列
- 悬停块左侧六点手柄可拖动排序（多条目组件同时出「组件」「本条」两个手柄：组件拖整组，可换章节；本条只在本组内换顺序，不能拖到组件外）。拖动时保留内容预览，蓝色插入线跟着手停的空挡，落点带滞回，不要跟着指针一步跳过多档；拖到底部垃圾桶可删除。拖 / 复制章头会带上紧跟的强线（`.sub` 导语在章头里一起走），不要只挪标题把线留在原地
- 独立分割线 `.rule` 很细，靠近线条即可右键「删除组件」（自定义文本里的弱分割线同样）
- 编号信息、数字卡、议题格等条目：右键「新增一条 / 删除本条」，条目左侧手柄可在组件内排序；只有一条时右键「删除组件」可删整块
- 图片右键、动效背景下可勾选「点击轮播」（`data-cycle`）：右侧出缩略图 + 图1 / +，没图时缩略图只留灰底，不要斜杠；悬停缩略图在原位浮出大图，拖行排序时收起；+ 在侧栏水平居中。点 + 可一次多选加入，点图名替换该张，拖行可改轮播顺序。勾选后点击按顺序渐现切换，不要打开大图，也不要闪一下铺满
- 图片 / 视频 / SVG 图示右键 →「替换」→ 可选一张或多张。单张仍替换当前图；多张且未开轮播会自动打开并把所选图加进去，已开轮播则全部追加。写入文件夹时按你选中的原文件落盘，轮播每张图单独命名，不要拿缓存或相邻槽位的图顶替，也不要盖掉别的组件已有的文件。右键容器还可「移除当前素材」
- 编号信息右键：布局（格子 A / 格子 B / 列表 A / 列表 B）、勾选「显示编号」和「背景」（勾选后可设背景色，默认纯色不是渐变）；勾选编号后位置 / 类型 / 字号出现在菜单右侧；格子列数用 − N +，范围 2–5。无编号就是关掉「显示编号」的编号信息。编号信息或议题格右键可勾选「配图」，图在整组信息的左 / 右（配图位置面板在编号位置右侧）。配图右键可换裁切 / 可滚动 / 宽图 / 海报，底部保留标题和说明。尺寸只拖配图外框（和图片组一样），图和说明在配图区域内上下左右居中；拖高时整组与左侧信息跟着变高，不要裁切文字和说明
- 数字信息右键勾选：前缀 / 后缀 / 说明；列数用 − N +，范围 2–5。横排数字是同一父组件的紧凑排。可切格子 A / 格子 B
- 封面右键切版式：左齐 / 居中 / 配图 / 图文分栏。配图和「动效背景」互不绑定：左齐 / 居中 / 分栏也能单独开动效，不要因此改成配图版式；这三种纯文字版式不要格子。只有封面菜单出「动效背景」，章头和普通图片不要这个勾选
- 章头右键可勾选「背景」：颜色 / 配图 / 动效。有背景时章头底下的强线不显示，但 `.sub` 导语必须还在色块里、分割线原本所在位置的上方
- 图片 / 视频容器（含封面配图）右键「移除当前素材」：去掉当前这张；开了轮播则只移除当前显示的那张
- 议题格可设列数 1–5 并切格子 A / B；观点可切换色块 / 浅底；图可切换裁切 / 可滚动 / 宽图 / 海报，右键可新增一条并用 − N + 改列数（1–5）。图墙拖高后各行均分高度，铺满只裁切不改卡片容器高
- 图表数据点改数字后，纵轴刻度按新最大值重算，折线和锚点留在图内
- 图 / 表 / 折线右键「尺寸」：拖右边改宽、拖下边改高；折线拖高后绘图区跟着拉高。图选「铺满」只裁切，不超出栏宽
- 基础 token 右键改数值，立刻作用于整页并写入当前主题；颜色点色块用取色器，也可改 hex；主题导入导出在目录 `index.html`
- ⌘Z / Ctrl+Z 撤销，⌘⇧Z / Ctrl+Y 重做（含改字、换图、变体、尺寸、删组、新增、排序）
- SVG 里的字也可以编辑；点空白图形则整图替换
- 带内部标签的格子（如价格 `<small>`）按 HTML 保存，不把样式冲掉
- 报告改动会写回当前文件夹的 `index.html`（换过的图进 `lib/media/`）。**用「打开报告.command」打开再编辑**，不要直接双击 HTML。把整个报告文件夹发给别人，对方同样用「打开报告.command」即可继续改。目录页 `data-catalog` 不写磁盘、也不读写 IndexedDB

## 接入

把本目录拷到报告旁（建议 `lib/editor/`），在 HTML 里：

```html
<link rel="stylesheet" href="lib/editor/seed-edit.css">
<script src="lib/editor/seed-edit.js" defer></script>
```

目录页引用同文件夹：`editor/seed-edit.css`。脚本会自行 `mount`。也可 `SeedEdit.mount()`。

右键图片还可「尺寸」：对齐（左/中/右）、拖右边改宽、拖下边改高、适应 / 铺满。表和折线图同样可拖宽高。
