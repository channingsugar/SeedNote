# seed-edit

只给流式模板 `templates/editorial-flow/` 用。分屏 `editorial-page` 用自己的 `assets/template.js` 编辑器，不要挂这份。

- 文字右键 →「编辑」→ 就地输入 →「完成」（Esc 取消，Enter 提交；选中后可改颜色、加粗；点旁边 token 色块即可换成主题色；自定义文本还可改字号、插入弱分割线，线为整行）
- 标题右键 →「删除本组」：删掉该标题及其下的组件（直到下一个同级标题）
- 空白处右键仍出编辑菜单，点「新增组件」才打开右侧悬浮面板，再点卡片插入（自定义文本在导语下；章头 / 小节标题 / 导语 / 来源 / 分割线 / 自定义文本不配图）
- 顶栏最右侧「演示 / 编辑」切换：演示态关闭编辑（右键、排序、新增、就地改字），只留阅读与看图
- 悬停块左侧六点手柄可拖动排序（多条目组件同时出「组件」「本条」两个手柄：组件拖整组，可换章节；本条只在本组内换顺序）。拖动时保留内容预览，蓝色插入线跟着手停的空挡；拖到底部垃圾桶可删除。拖章头会带上紧跟的强线，不要只挪标题把线留在原地
- 独立分割线 `.rule` 很细，靠近线条即可右键「删除组件」（自定义文本里的弱分割线同样）
- 编号信息、数字卡、议题格等条目：右键「新增一条 / 删除本条」，条目左侧手柄可在组件内排序；只有一条时右键「删除组件」可删整块
- 图片右键可勾选「点击轮播」：右侧出缩略图 + 图1 / +，没图时缩略图只留灰底，不要斜杠；点 + 可一次多选加入，点图名替换该张，拖行可改轮播顺序。勾选后点击图片按顺序渐隐循环，不再打开大图
- 图片 / 视频 / SVG 图示右键 →「替换」→ 可选一张或多张。单张仍替换当前图；多张且未开轮播会自动打开并把所选图加进去，已开轮播则全部追加。写入文件夹时按你选中的原文件落盘，轮播每张图单独命名，不要拿缓存或相邻槽位的图顶替，也不要盖掉别的组件已有的文件
- 编号信息右键：布局（格子 A / 格子 B / 列表 A / 列表 B）、勾选「显示编号」和「背景」（勾选后可设背景色，默认纯色不是渐变）；勾选编号后位置 / 类型 / 字号出现在菜单右侧；格子列数用 − N +，范围 2–5。无编号就是关掉「显示编号」的编号信息。编号信息或议题格右键可勾选「配图」，图在整组信息的左 / 右（配图位置面板在编号位置右侧）。配图右键可换裁切 / 可滚动 / 宽图 / 海报，底部保留标题和说明。尺寸只拖配图外框（和图片组一样），图和说明在配图区域内上下左右居中；拖高时整组与左侧信息跟着变高，不要裁切文字和说明
- 数字信息右键勾选：前缀 / 后缀 / 说明；列数用 − N +，范围 2–5。横排数字是同一父组件的紧凑排。可切格子 A / 格子 B
- 封面右键切版式：左齐 / 居中 / 配图 / 图文分栏；配图或分栏可右键「替换」换图。拖组件排序时封面不显示
- 议题格可设列数 1–5 并切格子 A / B；观点可切换色块 / 浅底；图可切换裁切 / 可滚动 / 宽图 / 海报，右键可新增一条并用 − N + 改列数（1–5）。图墙拖高后各行均分高度，铺满只裁切不改卡片容器高
- 图表数据点改数字后，纵轴刻度按新最大值重算，折线和锚点留在图内
- 图 / 表 / 折线右键「尺寸」：拖右边改宽、拖下边改高；折线拖高后绘图区跟着拉高。图选「铺满」只裁切，不超出栏宽
- 基础 token 右键改数值，立刻作用于整页并写入当前主题；颜色点色块用取色器，也可改 hex；主题导入导出在目录 `index.html`
- ⌘Z / Ctrl+Z 撤销，⌘⇧Z / Ctrl+Y 重做（含改字、换图、变体、尺寸、删组、新增、排序）
- SVG 里的字也可以编辑；点空白图形则整图替换
- 带内部标签的格子（如价格 `<small>`）按 HTML 保存，不把样式冲掉
- 报告改动会写回当前文件夹的 `index.html`（换过的图进 `lib/media/`）。**用「打开报告.command」打开再编辑**，不要直接双击 HTML。把整个报告文件夹发给别人，对方同样用「打开报告.command」即可继续改。目录页 `data-catalog` 不写磁盘、也不读写 IndexedDB

## 接入

把本目录拷到报告旁（建议 `lib/editor/`），在 HTML 里：

```html
<link rel="stylesheet" href="lib/editor/seed-edit.css">
<script src="lib/editor/seed-edit.js" defer></script>
```

目录页引用同文件夹：`editor/seed-edit.css`。脚本会自行 `mount`。也可 `SeedEdit.mount()`。

右键图片还可「尺寸」：对齐（左/中/右）、拖右边改宽、拖下边改高、适应 / 铺满。表和折线图同样可拖宽高。
