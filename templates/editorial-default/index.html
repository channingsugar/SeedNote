04 比较

用统一字段比较方案差异

表格适合结构化权衡。把“推荐 / 风险”写成可读结论，而不是留给读者自行推断。

04.a · 比较

用统一字段比较方案差异

方案 覆盖能力 实施成本 主要风险 结论
方案 A 完整 中等 需要跨团队协同 优先验证
方案 B 局部 较低 覆盖不足 作为补充
方案 C 有限 较高 收益不确定 暂不采用
比较原则：

先固定比较维度，再填入方案内容。任何新增字段都要同时出现在所有方案中，避免口径漂移。

模板使用说明

  1. 视觉完全由设计 Token 驱动。通过顶部主题控件切换内置主题，或导入设计系统导出的主题 JSON。
  2. 替换封面、章节标题、卡片文案、表格与证据位中的占位内容，无需改组件结构。
  3. 如需调整组件参数（列数、装饰线等），请回到设计系统画布修改并导出主题后导入本模板。
  4. 本模板与设计系统共用同一 `localStorage` 主题仓库键，浏览器内主题可互通。
