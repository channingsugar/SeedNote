Knowledge Report Template 一屏一个父组件 替换占位内容

一屏一种分页，格子里只换父组件

壳是封面、章封面、口径。内容屏只有 1 分区、左图右文、上图下文。每种分页把能放的父组件走一遍，标题是组件名，副题是使用场景。

模板使用说明

  1. 壳只有封面、章封面、口径。内容屏只有 1 分区、左图右文、上图下文。一个格子只放一个父组件。
  2. 1 分区：Callout、Card Grid、强调色、Stat Grid、List、Steps、Table、Bar Compare（横 / 竖）、Evidence（图片 / 截图 / 条带）、Media Switch 封面（单张 / 并排）。
  3. 左右右侧：默认文案、List、Steps、强调色、Bar Compare。上下底栏：默认文案、Callout、强调色、Card Grid、Stat Grid。
  4. 标题是组件名，副题是使用场景。套进报告时抄 class 和结构，不要按一组件一屏切。
  5. 不要加装饰线，不要把 `report-section__stack` / `report-split` 当分页。
  6. 视觉由设计 Token 驱动。主题与翻页栏默认隐藏，鼠标移到屏幕左下角才显示。
